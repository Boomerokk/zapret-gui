## Что это такое

**Zapret GUI** — десктопное приложение для Windows, которое позволяет запускать и управлять обходом блокировок [zapret](https://github.com/Flowseal/zapret-discord-youtube) через удобный графический интерфейс. Никаких консолей, никаких bat-файлов вручную.

Основано на [Tauri 2](https://tauri.app) — приложение весит ~10 МБ и не требует установки браузерных движков.

---

## Возможности

- **Запуск стратегий** — выбор из всех доступных `general*.bat` с группировкой по типам (ALT, Simple Fake, Fake TLS AUTO и др.)
- **Автоматический перезапуск** — при смене стратегии кнопка «Запустить» меняется на «Перезапустить»
- **Скачивание zapret** — загружает актуальный релиз с GitHub автоматически при первом запуске
- **Проверка обновлений** — уведомляет о новых версиях zapret
- **Управление службами** — Install/Remove Service через встроенный интерфейс без открытия консолей
- **Game Filter** — включение обхода для игрового UDP/TCP трафика
- **IPSet Filter** — управление фильтрацией по IP-адресам
- **Диагностика** — проверяет BFE, прокси, конфликтующие службы (Killer, Adguard, GoodbyeDPI и др.)
- **Обновление данных** — обновление `ipset-all.txt` и `hosts` файла из репозитория
- **Тёмная / светлая тема** — переключение одной кнопкой, сохраняется между сессиями
- **Системный трей** — сворачивается в трей, не мешает работе
- **Автозапуск** — через Планировщик задач Windows (работает с elevated-процессами), стартует одним из первых
- **Автозапуск стратегии** — при старте приложения автоматически запускает последнюю стратегию (с повторными попытками при ошибке сети)
- **Лог событий** — полный лог с возможностью копирования и сохранения в файл
- **Toast-уведомления** — мгновенная обратная связь для всех действий
- **Portable-версия** — работает без установки

## Требования

- **Windows 10 / 11** (x64)
- Права **администратора** (запрашиваются автоматически при запуске)

## Установка и запуск

### Вариант 1 — Установщик (рекомендуется)

1. Скачай `Zapret.GUI_1.0.1_x64-setup.exe` из раздела [Releases](../../releases)
2. Запусти установщик, следуй инструкциям
3. При первом запуске приложение предложит скачать zapret автоматически

### Вариант 2 — Portable

1. Скачай `zapret-gui.exe` из раздела [Releases](../../releases)
2. Положи в любую папку
3. Запусти — права администратора запросятся автоматически (UAC)

> **Примечание:** При первом запуске Windows Defender может показать предупреждение SmartScreen — это нормально для неподписанных приложений. Нажми «Подробнее» → «Выполнить в любом случае».

## Сборка из исходников

### Требования для сборки

| Компонент | Ссылка | Примечание |
|---|---|---|
| Rust | https://rustup.rs | Стабильный канал |
| Node.js LTS | https://nodejs.org | Версия 18+ |
| VS Build Tools | https://aka.ms/vs/17/release/vs_BuildTools.exe | Компонент «Разработка классических приложений для C++» |

### Шаги

```bash
# 1. Клонируй репозиторий
git clone https://github.com/Boomerokk/zapret-gui
cd zapret-gui

# 2. Установи зависимости
npm install

# 3. Режим разработки (запускать от администратора)
npm run dev

# 4. Сборка релиза
npm run build
```

После сборки файлы окажутся в:
```
src-tauri/target/release/bundle/
  nsis/Zapret GUI_1.0.1_x64-setup.exe   ← установщик
  zapret-gui.exe                          ← portable
```

> **Для dev-режима** запускай VS Code (или терминал) от имени администратора — иначе `winws.exe` не сможет работать с сетевыми драйверами.

## Как это работает

```
Zapret GUI (Tauri)
       │
       ├── Запуск стратегии
       │     └── cmd /c general*.bat  ──►  winws.exe (скрытый процесс)
       │                                        │
       │                                   WinDivert драйвер
       │                                        │
       │                               Перехват и модификация
       │                               TLS трафика Discord/YouTube
       │
       ├── Install Service
       │     └── sc.exe create zapret  ──►  winws.exe как Windows служба
       │
       └── Автозапуск
             └── Планировщик задач  ──►  ZapretGUI task (HighestAvailable)
```

## Часто задаваемые вопросы

**Q: Почему нужны права администратора?**  
A: `winws.exe` использует WinDivert — низкоуровневый драйвер перехвата сетевых пакетов, который требует прав администратора на Windows.

**Q: Антивирус ругается на winws.exe / WinDivert**  
A: Это ложное срабатывание. WinDivert — легитимная библиотека перехвата трафика, используется во многих сетевых инструментах. Добавь папку zapret в исключения антивируса.

**Q: Не работает стратегия**  
A: Попробуй следующую по списку (ALT2, ALT3... или FAKE TLS AUTO). Провайдеры используют разные методы DPI, поэтому разные стратегии работают у разных пользователей.

**Q: Автозапуск не работает**  
A: Приложение использует Планировщик задач Windows. Задача называется `ZapretGUI`. Можно проверить в `taskschd.msc`. При запуске Windows стратегия стартует через 5–10 секунд после входа (ждёт инициализации сети).

**Q: Конфликт с другими VPN / обходами**  
A: Zapret несовместим с GoodbyeDPI, Adguard, некоторыми VPN-клиентами и службами Killer/Intel Connectivity. Используй встроенную диагностику (вкладка «Инструменты» → Run Diagnostics) для обнаружения конфликтов.

**Q: Где хранятся файлы zapret?**  
A: `%APPDATA%\com.zapretgui.app\zapret\` — открыть можно кнопкой «📁 Локальные файлы» в настройках.
